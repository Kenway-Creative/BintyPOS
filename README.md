# BintyPOS

Hot Water Comedy Club interactive concept demo.

Open index.html in a browser to try it locally.

To publish: Repository Settings > Pages > Deploy from a branch > main > root.

This is a prototype with simulated payments and sample prices. It does not connect to Dojo, Spektrix, printers or any live stock system. It uses browser memory, so reloading resets the data.

Demo: combine products from different vendors into one basket, check stock deductions, view vendor reports, change till menus and prices in the back office.

Not suitable for real trading or card payments.
